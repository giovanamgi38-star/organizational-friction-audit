# Matriz simple para priorizar fricciones

Esta es una **heurística de trabajo**, no un instrumento validado. Úsala para orientar conversaciones, no para producir conclusiones automáticas.

Para cada fricción, asigna una puntuación del **1 al 3** a estos criterios:

| Criterio | 1 | 2 | 3 |
|---|---|---|---|
| Frecuencia | Ocasional | Semanal | Diaria / muy recurrente |
| Impacto | Molestia limitada | Retraso o retrabajo relevante | Afecta resultados, servicio o bienestar |
| Facilidad de actuar | Complejo / depende de terceros | Requiere coordinación | Cambio pequeño bajo control del equipo |

**Puntuación orientativa:** Frecuencia + Impacto + Facilidad (de 3 a 9).

Un puntaje alto significa que conviene **explorarlo antes**, no que deba implementarse sin validación.

| Fricción | Frecuencia (1–3) | Impacto (1–3) | Facilidad (1–3) | Total | Cambio propuesto | Responsable (rol) | Indicador |
|---|---:|---:|---:|---:|---|---|---|
| Ejemplo: aprobaciones tardías | 3 | 3 | 2 | 8 | Acordar niveles de autorización y plazo de respuesta | Dirección + operaciones | Días medianos de aprobación |
| | | | | | | | |
| | | | | | | | |

## Decisión final

1. Verificar las causas con las personas que hacen el trabajo.
2. Seleccionar 1–2 mejoras pequeñas como piloto.
3. Definir línea base e indicador antes de cambiar el proceso.
4. Revisar resultados y efectos no deseados.
5. Ajustar, mantener o retirar el cambio según la evidencia.
